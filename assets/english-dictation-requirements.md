# english-dictation-app 项目需求

## 1. 项目目标
开发一个可在线访问的网页应用，用于英语单词听写练习。核心闭环：
1. 用户上传一张包含英语单词的图片（如课本单词表照片）。
2. 应用自动识别图片中的英文单词，提取为单词列表。
3. 应用逐个播放单词发音（TTS）。
4. 用户在输入框中拼写听到的单词，提交后即时判断对错。
5. 练习结束后展示正确率与错词列表。

## 2. 技术约束
- 前端：需要上传区域、播放控制、输入框、结果反馈界面。界面简洁，适合学生使用。
- OCR：调用扣子可用的 OCR 能力，从上传图片中提取英文单词。
- TTS：调用扣子可用的语音合成能力，为每个单词生成发音。注意控制调用频率，避免不必要的额度消耗。
- 数据存储：练习结果（正确率、错词）至少在单次会话内保留，无需长期持久化也可接受。
- 部署目标：最终代码需可推送到 GitHub 仓库，并可通过 GitHub Pages 或扣子自带部署能力上线。

## 3. 功能开发优先级
P0（必须完成）：
- 图片上传与 OCR 识别，输出单词列表
- 逐个播放单词发音
- 输入框拼写与对错判断
- 练习结束展示正确率

P1（有余力再做）：
- 错词自动加入复习队列
- 发音语速可调
- 界面美化（移动端适配）

## 4. 验收标准
- 上传一张包含至少 5 个英文单词的图片，能正确识别出 ≥80% 的单词
- 点击播放后能听到单词发音，发音清晰可辨
- 输入正确时显示"正确"，输入错误时显示"错误"并展示正确答案
- 练习结束后显示正确率
- 代码已推送到 GitHub main 分支
- 应用可通过公网 URL 访问

## 5. 注意事项
- 额度控制：TTS 调用按次计费，开发调试时可先用 2-3 个单词的小列表测试，功能稳定后再用完整列表验证。
- 不要泄露密钥：如果涉及 API Key，通过环境变量管理，不要把真实值写入代码或提交到仓库。
- GitHub 仓库权限：扣子目前仅支持绑定 owner 为当前授权账号的仓库，不支持组织账号仓库。
